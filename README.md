# StockIQ extension for Claude Desktop

The StockIQ extension connects the Claude Desktop app to your StockIQ instance through the StockIQ MCP Service.

## Download

| Extension | Download |
| --- | --- |
| StockIQ (production) | [stockiq.mcpb](https://github.com/stockiqtech/siq-mcpb/releases/latest/download/stockiq.mcpb) |
| StockIQ Sandbox | [stockiq-sandbox.mcpb](https://github.com/stockiqtech/siq-mcpb/releases/latest/download/stockiq-sandbox.mcpb) |

These links always download the latest version. Earlier versions are listed under [Releases](https://github.com/stockiqtech/siq-mcpb/releases).

To install, open the downloaded file. Claude Desktop installs the extension and asks for your StockIQ URL and an MCP token. To update, open a newer file the same way.
